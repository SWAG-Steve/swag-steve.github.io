FamilyAI Privacy Policy

Last updated: October 26, 2026

What it accesses. With the account owner's permission, FamilyAI reads and updates the family's own Google Calendar, Tasks, and Gmail through Google's official APIs.

How data is used. Data is used only to show the family's schedule, tasks, and messages to family members inside the family's private assistant running on a home computer.

Storage. Data stays on the family's own computer. It is not sold, shared, or transferred to any third party, and it is not used for advertising.

Google API Services User Data Policy. FamilyAI's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions.
